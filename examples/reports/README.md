# Reproducible reports

Run `examples/fixture.yaml` on an unlocked Windows desktop to generate a failing evidence bundle. The fixture must expose clipping, overlap, off-screen placement, an unexpectedly disabled action, a missing click response, and blank content.

See [`windows-fixture-150-percent.md`](windows-fixture-150-percent.md) for a sanitized real-machine run that pairs the intentional-defect result with the clean regression.

Run `examples/fixture-clean.yaml` after switching the fixture to clean mode. Deterministic checks and AI visual review must pass without findings.

Reports generated by a real machine may be added here only after usernames, hostnames, private addresses, device IDs, tokens, paths, and screenshot content are reviewed for publication.
